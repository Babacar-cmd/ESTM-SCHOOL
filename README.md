## Déployer sur streamlit.app (2 minutes)

1. Crée un repo GitHub (ex: glar-master-streamlit)
2. Push ces fichiers:
   - app.py
   - requirements.txt
3. Va sur https://share.streamlit.io/
4. New app -> Choisis ton repo -> Main file: app.py -> Deploy

URL finale: https://ton-nom-glar-master-streamlit.streamlit.app
